# 全量保真验证与方法调研

日期：2026-10-17。用户本轮要求优先保留所有原图细节；旧文档中的单字 500 节点、少颜色和五秒指标不作为本轮“无损”的替代标准。

## 结论与边界

实际测试 `samples/images/` 全部 25 张 PNG。原图逐张 SHA-256 保持不变，既有未提交编辑未回退。旧版完成 25 次服务调用；旧版 VTracer 两种分层、新版 VTracer 三种配置共完成 125 次额外转换。最终分别输出 25 份保真曲线模式 SVG、25 份原像素路径 SVG，并从保存的 SVG 独立重新渲染核对原文件。

**没有实现普遍保证的“平滑曲线、少节点、任意放大完全无失真”。** 位图记录有限网格采样，多个不同矢量设计可能产生同一位图，缺失的连续边界和图层无法唯一恢复。所谓矢量任意放大不模糊，不能证明自动描摹准确恢复了原设计。纯像素路径也是这种区别的重要反例。

原像素路径没有内嵌位图，只含整数坐标矩形路径和原始颜色/透明度；横向同色游程与纵向相同游程合并，不删任何可见样本。25/25 在 resvg 原分辨率的 8 位预乘 RGBA 回渲中完全一致，预乘样本最大误差为 0。原 alpha=0 的隐藏 RGB 不保存；透明样本经渲染器反预乘后，黑白底浮点合成最大误差不足 1/255，这属于整数舍入，报告未将它写成直通 RGBA 字节完全一致。这个结果的保证范围限于所述网格和实测渲染器，放大仍有像素网格，不等于平滑字体路径。

保真曲线采用隔离的 VTracer 1.0.0a4 共享边界 cutout；原色、无碎点过滤、不重新压缩节点。另比较 watershed，按原图而非预处理掩膜的主体色差选择结果。目检发现仅按均值择优会接受渐变内部的细条纹，因此加上平滑内区 Laplacian 误差；只在与最低主体平均色差相差不超过 0.8/255 的候选内，按“主体平均色差 +4×平滑内区 Laplacian 平均误差”择优。这个限制防止为平滑而明显损伤飞白、光晕等纹理。两项分别记录，不把选择分数写成还原率。透明单色再比较原 alpha 覆盖率轮廓。所有候选都不是通过改变原图获得好分数。

保真模式保留原背景和原画布：为避免占多数的背景改变分区算法，将确切单色边框外的非背景区域连同缓冲区送入追踪，再用整数平移放回原坐标，并补上原背景。它不校斜、不增强、不去噪。对复杂背景 `22_busy_bg`，全图有 132106 种 RGBA 颜色；本轮选择完整像素路径回退，输出约 22.4 MB。它保留背景，不能冒充干净的字形路径。所有输出均明确记录 `representation`。

## 旧版损坏的原因

截图对应 `11_3d.png`。旧轮廓管线会合并小色层、形态学清理、过滤碎块、曲线平滑，并在归一化 VTracer 输出时按节点预算再次拟合。细密阴影不是杂点；这些操作把密集平行线压成了灰块，局部颜色块侵入字身。只检查阈值掩膜 IoU 或主色匹配，不能发现这些空间细节损失。

新模式直接对原始 RGBA 在黑底、白底的合成色差取最大值，另报主体均值、最坏像素、99 分位及误差 >8 的像素数量。完整原始证据见 `eval/results/full_folder_fidelity/final.json`，旧版、新候选及回渲 PNG 也保留在各样本目录。旧版 `22_busy_bg` 做过旋转和裁切，不能与原坐标新版硬凑直接优劣数字；报告明确标记不可同坐标比较。

还应考虑的工程路径：如果能取得原 TTF/OTF、原文字排版和阴影参数，应直接导出字形轮廓并重建效果，避免先栅格化再恢复；只用 OCR 重新打一遍字无法保证同一字形、笔画、字距、颜色、阴影和飞白。没有原设计时，交互式描摹与逐区域修正仍是高质量可编辑交付的重要步骤。

## 使用与复现

网页新增“保真曲线”“原像素路径”，前者为网页默认；旧质量/均衡/精简档仍保留，其 API 默认值保持原契约。新增模式明确禁用不生效的节点、颜色、杂点、专色等控件，避免伪装可调。统计不再显示单色主色匹配当作全部还原度。

```powershell
# 项目已有 0.6 依赖保持不动。新版从官方 PyPI 单独装入项目目录。
.venv/Scripts/python.exe -m pip install --target .tools/vtracer1 --no-deps --only-binary=:all: vtracer==1.0.0a4
.venv/Scripts/python.exe cli.py convert samples/images/11_3d.png -o out/fidelity --preset fidelity
.venv/Scripts/python.exe cli.py batch samples/images -o out/pixel_exact --preset pixel_exact --no-preview
.venv/Scripts/python.exe eval/full_folder_fidelity.py
.venv/Scripts/python.exe eval/full_folder_fidelity.py --v0
.venv/Scripts/python.exe eval/full_folder_fidelity.py --v1
.venv/Scripts/python.exe eval/full_folder_fidelity.py --final
.venv/Scripts/python.exe eval/build_fidelity_report.py
.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider tests
node --check app/static/app.js
node tests/frontend_workflow.mjs
```

主要交付限定 SVG。没有把 PDF/AI/EPS 导出后的结果也宣称为像素精确；它们的抗锯齿、透明度和路径导入需要独立验证。Illustrator 实机编辑及其他浏览器一致性也不能由 resvg 测试替代。原像素路径文件大且难编辑，新曲线包含保留的抗锯齿色区，均不承诺单字 500 节点或五秒性能。

自动测试：111 项通过，前端 JavaScript 语法检查和批量参数快照/ZIP 流程检查通过。修复了旧飞白候选在先被几何/颜色检查拒绝时不记录纹理检查的问题：仍保留独立 PDF 几何门槛，纹理另外使用 resvg 记录，避免 MuPDF 无法处理超长渐变时丢失该诊断；没有放宽纹理阈值。另新增随机 RGBA、孤立像素/孔洞、原画布保留、API 立体字、大面积空白掩盖误差及飞白不可被平滑错误替代等 6 项测试。
