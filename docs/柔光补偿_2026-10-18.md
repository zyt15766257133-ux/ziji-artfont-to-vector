# 光晕与软阴影补偿实施记录

2026-10-18。已接入保真曲线档，默认开启。采用前必须与原流程进行源图和局部比较；不满足条件时保留原 SVG。原像素路径档不使用此推断。

## 实际实现

入口为 `app/pipeline/fidelity.py`，拟合和局部检查位于 `app/pipeline/soft_effects.py`。

1. 先完成原 VTracer 曲线候选和回渲，保存可靠的对照结果。
2. 从原图分析背景、平坦不透明字身以及宽而平滑的外部效果。尖锐装饰、纹理、复杂背景或缺乏字身依据时跳过。
3. 拟合高斯扩散半径、偏移、颜色、透明度及弱光截止值，重建字身覆盖率，再用现有轮廓拟合器生成字身曲线。拟合 ROI 最长边限制为 420 像素，每次优化设迭代上限。
4. 检查字身内孔和连通性、交并比与边缘覆盖率。优先尝试一个整体笔画发光源；失败后，可对 2～6 个不连通发光源分别拟合多色效果。
5. 检查原图定义的光晕、弱光晕、字身、边缘、扩散距离分段、逐发光源区域和额外溢光。透明素材同时检查黑底和白底合成。
6. 仅在局部检查通过、光晕误差改善且节点减少时采用新 SVG。新 SVG 包含原背景、独立柔光效果和字身，整组笔画只做一次模糊，避免交叠处叠亮；原色块光晕被替换。

复杂度控制先尝试一个效果层，再进行必要的分区；删除低贡献效果时同时检查局部和弱光误差。这仅借鉴 Optimize & Reduce 的优化与约简思路，没有复现其完整算法，也没有引入 SGLIVE、Bézier Splatting 或 VTracer 2.0。

## 本版范围

支持平坦单色、不透明字身，以及纯色不透明背景或完全透明边界上的平滑柔光/软阴影。可拟合有偏移的效果，以及不同不连通字形周围的不同光色。

连续笔画上的任意多色变化、复杂渐变字身、厚硬描边与多重柔光组合、纹理背景等不保证可分离，当前依靠检查保留原流程。不能据此宣称任意图片无失真；字身曲线也仍为近似。

SVG 的高斯模糊为参数化可编辑效果，没有嵌入位图。PDF/AI 通过现有导出器近似展开成透明度矢量层，可能产生色带及额外节点、耗时。EPS 无法承载这些透明滤镜，会报错。Illustrator、Safari 实机编辑仍需验收。

## 使用与对照

网页选择“保真曲线”，切换“光晕与软阴影补偿”，对同一图片重新转换。结果显示是否采用效果和光晕明暗偏差。批处理开始时固定此参数。

API 的 `/api/convert`、`/api/jobs`、`/api/batch` 和样例转换接口接受表单字段 `soft_effects=true/false`，默认 `true`。此字段进入样例缓存键；性能评估建议上传图片，避免缓存影响。

```powershell
.\.venv\Scripts\python.exe cli.py convert samples/images/21_neon.png --preset fidelity -o out/soft-on
.\.venv\Scripts\python.exe cli.py convert samples/images/21_neon.png --preset fidelity --no-soft-effects -o out/soft-off
```

本轮新代码验证服务运行于 `http://127.0.0.1:8766/`。已有 8765 服务仍是旧进程，静态页面可能已变但后端需要重启才能载入代码。评估请使用 8766，或自行重启常用服务。

前后对照入口：`http://127.0.0.1:8766/soft-effects-results/report.html`。支持选择 25 张内置图和 4 个独立设计的 SVG 参考，切换最终 SVG 与已核验 PNG、下载 SVG、查看阶段耗时及拒绝原因。

### 耗时状态

本轮 25 张完整调用中，霓虹约 5,474 ms，阴影约 5,348 ms，均超过五秒。阴影虽然进行了候选计算，但局部比较拒绝，最终仍保留旧流程。另一次独立 HTTP 上传的霓虹调用：开关关闭时服务约 2,191 ms，开启时约 5,020 ms；HTTP 总时间分别约 2,220/5,025 ms。机器负载和渲染进程冷热会影响数字，不用单次波动代替性能验收。

服务计时已包含解码、验证、原流程候选、柔光候选、回渲检查及启用的预览；不包含排队、网络、浏览器显示和其他文件格式导出。`stats.timings_ms` 可查看原流程与补偿阶段，顶层 `timings` 可查看解码与预览耗时。当前阶段完成了质量补偿和可评估入口，尚未通过五秒验收。
