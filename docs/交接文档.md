## 2. 本轮已完成工作

### 2.1 口径修复（原 P0）

- 字数：`VectorizeOptions.glyph_count` + API `glyph_count` 字段 + manifest 传递；内置样本自动取 manifest 真实文字与字数，连通域估算仅兜底（`glyph_source` 标注）。14 号毛笔按 1 字计。
- C3 节点：唯一规则 50~500（check 名 `node_50_500`），删除「单层单字」放宽；新增 `subpath_count`、`node_floor_estimate`（子路径×6）说明结构性下限。
- C6 内孔：不允许少孔，阈值统一 ≥24px²。修复过程定位并修掉两个真因：`_clean_layer_mask` 的闭运算把楔形小孔挤窄（改为只封 <9px 缝隙）、小孔被前景噪点门槛误杀（孔洞独立低门槛 4px²、面积缩水 >5% 时收紧容差重拟合、叠加层孔节点上限 `max_hole_nodes`）。
- 颜色参考：指标与图层填色一律取未经 CLAHE/去噪的原始像素（`PreparedImage.rgb_raw`），图层取色只统计贴近本层主色的实心像素（防边界混色拉偏）；报告同时给出增强像素参考值与差值。
- 单/多色判定：主色全部落在「背景→最大主色」连线上的判单色（飞白灰阶归单色），离线颜色或渐变判多色。单色考核改为需求原文的主色色值偏差 ≤3%，多色主色匹配 ≤8%。
- C2：原图无角点时角点项不计、按剩余权重重归一（不给满分），报告角点平均/最低并标注。
- C7：`format_check` 改 XML 解析器；SVG 标题与 data-name 转义（`svgutil.to_svg` 用 `quoteattr`/`escape`）。
- 真值口径：`samples/generate_samples.py` 同步产出 `samples/truth/*.png`，规则「与可见背景色差 >20」（与预处理同口径，透明底用 alpha，22 号用显式字形）；`evaluate(truth_mask=...)` 输出 `truth_shape_iou` 等与 `checks_truth`，与自参照口径并列。
- 验收文档与代码对齐：裁切 50%、重试 3 轮（代码确为 3 阶段）、内孔结论、单字节点表述全部重写。

### 2.2 需求补齐（原 P1）

- 13 号白色装饰点保留：前景色差阈值 30→20，候选字色 k=5→10、占比门槛 0.5%。
- 无效输入（5.6）：`QualityReport.invalid/invalid_reasons/photo_like/orig_bbox_ratio`；背景杂乱、模糊、过曝、无前景判异常，默认提示不拒绝（`input_invalid` 进指标），严格模式拒绝；主体占画面 <60% 为建议级提示+自动裁切（严格模式拒绝）；疑似照片给提示。22 号预期判异常由 `EXPECTED_INVALID` 自动核对。
- 模糊度改为「前景合成浅灰底」图上的主体外接矩形内拉普拉斯方差（透明底素材 RGB 与字色相同只靠 alpha 区分，旧口径会误判）。
- 渐变：全局渐变判定改为「剔除 ≥18% 单一纯色层 + 分箱中位数两遍拟合 + 合并 R²」，支持带描边的渐变字输出「渐变层+描边层」双层（24 号=需求 5.3 标准案例）；径向渐变检测与输出（`build_radial_gradient`，按实际半径跨度归一化），栅格化与 EPS 限制同步处理；色阶颜色取原始像素。
- 专色匹配：`spot_colors` 选项（API/CLI），平面色层偏差 ≤3% 替换为专色，`_match_spot` 有测试。
- 按字分组：`assign_glyph_groups`（路径中心 k-means，按行列排序，固定种子），输出 `glyph-N` 分组、`data-name` 为真实文字；`pathparse.parse_svg_layers` 重写为嵌套感知解析（并修掉 `d="` 误匹配 `id="` 的 bug），`export.py` 复用同一解析器。
- 轮廓杂讯：断笔数、孤立碎点（<20px²）、毛刺占比（3×3 开运算/周长）入指标与 checks（毛刺阈值 2%，手写体细笔锋敏感）；冗余控制点比例 `redundant_anchor_ratio`（C 段中点偏离弦 <0.3px 占比）。
- 导出：`fmt=ai` 输出 `.ai` 文件名（PDF 兼容），`validate_export` 做 PDF/EPS/SVG 结构校验，`out/export_check.json` 25/25 通过。注意 `/api/export` 曾漏处理 ai 回落成 SVG，已修。
- 稳定性 10 次 × 全部样本（0.00%）；批量 100 张实测 290 秒（`out/batch100/`）；浏览器一致性改用 Chrome/Edge 无头实测（`eval/browser_render_check.py`，灰底页面+边界距离口径，因浏览器抗锯齿伽马与内部栅格不同，掩膜 IoU 只有 ~92% 但边界平均偏差 0.58px）；峰值内存用 tracemalloc 单独一次转换测（全程开启会拖慢计时 3 倍）。

### 7.3 纹理压平（工程改动，`app/pipeline/preprocess.py`）

诊断链路：旧卡扫描件边缘是深色边框 → 背景估成深色 → 整张纸当前景（主体 93%）→ 主色是纸色却被判单色（色偏 91% 拿纸比黑墨）→ 引擎自检切换 vtracer 剥掉纸层、留下墨加霉斑（单卡 6107 节点、37 秒）。

实现 `_flatten_paper_texture`：前景中位色为纸色 → 颜色距离直方图谷底定霉斑容差（40~90）→ 剔除大面积近色区块；五道误伤防护（前景占比 ≥0.55、外接矩形填充 ≥0.85、纸色亮度 ≥90、主色距离 p50 ≤60、字色质量 ≥1.5%）；局部梯度保护（Sobel>14 + 3×3 膨胀）保淡笔画。参数迭代 4 版定版（过程对比图 `out/texture_debug/`）。
