# 字迹 · 艺术字转矢量

本地运行的艺术字位图转矢量工具，提供 Web 界面、API 和 CLI。支持 PNG/JPG/WEBP 输入，以及 SVG、PDF、PDF 兼容 AI 和部分 EPS 输出。

当前开发版本为 `1.2.0-dev`。原始需求作为验收依据，未通过项继续记录。开发服务的验证入口为 `/validation`，原始证据由启动时的 `ZIJI_EVIDENCE_DIR` 指定。

## 启动

需要 Python 3.10～3.12 和 Node.js 22+。SVG 渲染使用常驻 resvg 进程。

```bash
pip install -r requirements.txt
npm ci --prefix eval/tools
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

访问 `http://127.0.0.1:8765/`。原有 `python -m app.main` 入口仍使用 8000 端口。

## 使用

首屏只保留上传、示例和单张/批量入口；参数不会在选图前占用画布。上传图片后检查素材提示并开始转换，结果会显示在大画布中，颜色图层和转换设置位于右侧；窄屏设备会将它们排列到结果下方。滑块、并排、差异和源码视图用于检查细节，转换详情默认收起。

颜色图层面板按 SVG 中实际使用的填充、描边和部分滤镜颜色分组。点击色块可以改色，眼睛按钮可以暂时隐藏该层，“恢复原始”会精确还原转换完成时的 SVG。编辑会立即更新预览、历史记录和 SVG/PDF/EPS/AI 下载；此时画面指标仍属于改色前的转换结果，界面会明确提示。渐变会保留原定义并作为整体显示，当前不拆分渐变色标逐个改色。复杂素材可能包含多个相近颜色层。

填写实际字数可以核对节点预算。选择档位后可以重新转换，再选择格式下载。批量模式支持文件夹导入，批次开始时固定参数，ZIP 保存原文件映射，重名输出自动加后缀。

转换后，结果指标区自动显示“原图主色”：最多 8 种代表色的色块、HEX 和 RGB 值。取色使用改色前的原图，排除透明像素及检测到的背景；渐变和柔边以代表色展示，不表示图片的全部色阶。无需开启专色匹配，开启改色后这里仍展示原图颜色。旧历史记录需重新转换才能生成颜色数据。

专色匹配是可选流程，默认关闭。展开参数设置，填写 HEX 色板（如 `#1a2b3c,#d4af37`）并打开“启用专色匹配”，重新转换后将纯色填充层映射到色板中 RGB 距离最近的颜色；支持保真、普通档及 VTracer、单张和批量，结果区显示改色层数。支持 `#RGB` 和 `#RRGGBB`，开启后空色板或无效色值会报错。原像素路径模式禁用该功能。SVG 渐变定义、透明度及已独立标记的背景层保留；渐变若已被转换为纯色色块，也会按纯色层匹配。主动改色产生的原图色差仍如实显示。

API 需同时提交 `spot_matching=true` 和 `spot_colors=#1a2b3c,#d4af37`；仅提交色板不启用匹配。CLI 使用 `--spot "#1a2b3c,#d4af37"` 显式开启。当前是用户自定义 HEX 色板映射，不含 Pantone 色库、ICC 印刷色彩管理或 PDF 专色分色输出。2026-10-19 工程验证见项目上一级 `专色匹配验证_2026-10-19/验证说明.md`。

2026-10-18 按用户要求，当前业务验收素材限定为纯白底、PNG/JPG/WEBP、双边均≥500像素、单张≤5MB、艺术字主体占比≥60%，排除复杂背景、强反光和模糊畸变。已删除两批不适用的真实素材、对应采集/测试文件及内置复杂背景样本。

保留的 24 张历史合成图片仅用于诊断，包含非白底和主体占比不足的输入，尚未按当前纯白底准入条件完成筛选，不能计作业务验收集。历史百张记录也不能代替当前业务素材验收。

## 当前改进

2026-10-18 浅纸底补充：对近中性灰、近均匀浅色纸底的单色素材，估计纸色和背景颗粒后输出透明原生像素覆盖路径，避免把颗粒和横向纹理描成大量失真曲线。不做CLAHE、锐化或重绘；原图自带柔化仍保留。这是保留原分辨率纹理的回退，不能算低节点平滑曲线达标。彩色/场景/明显不均匀背景仍不使用该分支。

2026-10-18 自动去背景修正：网站默认“保真曲线”会去除干净纯色背景（包括白底、黑底），输出真正透明的SVG；保持原画布和左侧原图。已有透明输入保留alpha，非均匀背景提示未去底。去底后修正抗锯齿边缘底色；采用柔光模型的素材移除独立背景层并保留光晕。误差改为将透明结果合成回原底色后与原图比较，这不代表透明层真值已经通过验收。“原像素路径”继续用于原图像素存档。以下保留原背景的表述是此次修正前的历史行为。

2026-10-17 新增网页默认“保真曲线”和“原像素路径”。两者保留原背景、画布及透明度，不强制节点上限；前者采用隔离的 VTracer 1.0 共享边界曲线，后者输出像素网格路径，放大仍有像素格。曲线仍为近似，不能保证任意放大完全无失真。全部 25 张的逐图证据、安装步骤和方法调研见 [全量保真验证](docs/全量保真验证_2026-10-17.md)；服务内入口为 `/fidelity-results/report.html`。

2026-10-18 在“保真曲线”增加默认开启的“光晕与软阴影补偿”：字身与柔光分别拟合，通过局部回渲检查后，用独立 SVG 效果替换色块光晕。关闭开关可对照原流程；不适用或局部误差未改善时自动保留原输出。霓虹样例的光晕平均误差由 2.502 降至 0.707/255，完整调用约 5.47 秒，本轮尚未通过五秒验收。实现范围、证据和使用方式见 [柔光补偿](docs/柔光补偿_2026-10-18.md)；本机对照页为 `/soft-effects-results/report.html`。

同日新增网站兼容接入：上述数据为接入前记录。当前“保真曲线＋柔光补偿”自动生成可识别的标准投影/模糊链；单一整体发光源附着在字身复合路径上，多色发光源独立保留。网站上传、异步转换、SVG 下载和批处理共用此转换实现，不读取小样结果。最新本机入口为 `http://127.0.0.1:8768/`，也可运行 `start_vectorcraft_compatible.cmd`。实际浏览器下载后导入 VectorCraft，光晕、改色、移动、取消外层编组及保存重开通过“夜行”本例；131项测试通过，网页转换约5.5秒，仍未通过五秒或全素材兼容验收。详见 [网站兼容柔光](docs/网站兼容柔光_2026-10-18.md)。

清洁素材直接保留原始像素边界，避免增强、去噪和误判倾斜损伤细字。单色字优先采用受节点预算及局部拓扑检查约束的三次曲线拟合。复杂背景图片不计入当前业务素材与验收范围。

预览和指标使用 resvg 渲染，正确处理透明度、绘制顺序、渐变和滤镜。PDF 中的纯色柔边效果展开为可编辑的透明度矢量层，再用 MuPDF 对照回渲；这会增加导出节点及导出时间。

## 已知缺口

飞白纹理在当前节点预算下仍有失败。部分立体字特征和局部小孔诊断也未通过。单字节点必须结合真实字数和逐字分布检查，整体平均值仅供诊断。

EPS 无法保留当前文件中的透明度与滤镜，会明确报错。AI 为 PDF 兼容形式，Illustrator 2020+ 实际打开编辑和 Safari 实机仍待验证。WebKit 测试引擎的结果单独记录。

单张 ≤5 秒按完整服务调用记录，包含指标和启用的预览；HTTP、排队及文件格式导出另外计时。样本缓存响应标注 `cached`，不计入转换性能证据。

## 可选第三方服务

已提供官方 Vectorizer.AI 适配器，环境变量为 `VECTORIZER_API_ID`、`VECTORIZER_API_SECRET` 和 `VECTORIZER_API_MODE`。默认 `test` 模式会带水印。`production` 模式会使用账户额度。凭据只在服务环境读取，状态接口不返回凭据。

`GET /api/providers` 查看配置状态，`POST /api/provider/vectorizer_ai/convert` 使用表单 `file` 上传。当前本地转换不会自动把图片发送给第三方。官方服务需要账户凭据；公开网页演示只能预览，下载会跳转订阅页。

```bash
node --check app/static/app.js
node --check app/static/color-layers.js
node tests/frontend_workflow.mjs
node eval/verify_studio_ui.cjs
```

`eval/verify_studio_ui.cjs` 需要先启动本地服务，默认检查 `http://127.0.0.1:8768/`；可用 `ZIJI_TEST_URL` 指定其他地址。它会执行真实上传、转换、颜色编辑、图层显隐、历史恢复、响应式布局和批量 ZIP 下载，并把截图及机器可读结果保存到项目上一级 `UI改版验证_2026-10-20/`。

原始需求见项目上一级 `docs/艺术字图片转矢量图-需求.docx`，验收规则见 `docs/艺术字矢量化验收标准.md`，接口与部署说明见 `docs/部署文档.md`。
